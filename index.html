MIPS32 5-Stage Pipelined CPU (Verilog)

Project Details

Designed and simulated a MIPS32 static 5-stage pipelined CPU using Verilog and Vivado.

  • Instruction Set: Implemented 21 instructions including R-Type (ADD, SUB, AND, XOR), I-Type (ADDIU, LW, SW, BEQ), and J-Type (JAL, JR).
  • Hazard Handling: Implemented delay slot technology to handle control hazards caused by branch instructions, and handled structural hazards by stalling upstream pipeline stages.
  • Modules: Wrote custom Verilog modules for program counter, decoding, general registers, execution, memory access, and a custom 32-bit comparator.
